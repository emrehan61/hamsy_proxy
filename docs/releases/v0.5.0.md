# Hamsy 0.5.0

Hamsy now includes a local MCP server and an agent CLI. Run `hamsy mcp --print-config` to configure your MCP client. Hamsy starts or reuses a local capture instance when the client connects.

- Inspect and search live traffic or HAR sessions opened in Hamsy. Search supports literal text and regular expressions, and match context returns bounded, redacted previews.
- Follow changes in live capture with a cursor, preview rule effects against retained traffic, and export redacted HAR data for selected requests.
- MCP starts in read-only mode. Rule and capture changes require `--allow-writes`. Replaying a captured request requires a separate `--allow-replay` opt-in.
- Open HAR archives without starting capture using `hamsy open session.har`. The macOS and Linux installers include desktop file integration.

See the [Hamsy agent guide](https://github.com/emrehan61/hamsy_proxy/blob/v0.5.0/docs/AGENT_GUIDE.md) for setup and tool details.
