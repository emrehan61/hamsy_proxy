# Hamsy 0.5.0-beta.5

Agents can now edit current rules and explicitly enable or disable them without
resending masked values or private payloads.

- `edit_rule` updates only supplied rule fields by ID. Omitted fields are preserved.
- `set_rule_enabled` assigns `enabled: true` or `false`, preserving the rest of the
  rule. Repeated calls keep the requested state.
- Rule changes persist and update the live rule engine and web UI immediately.
- Partial edits are serialized with other rule changes. Invalid patterns, empty
  edits, and attempts to save masked values are rejected.
- `create_rule`, complete replacement via `update_rule`, and `delete_rule` remain
  available. The write connection now exposes 16 tools; read-only connections
  expose the same 9 tools.

Generate configuration using `hamsy mcp --allow-writes --print-config` and
reconnect your agent. Automatic Hamsy startup remains enabled. Both the MCP
binary and the running app need beta.5 or later for the new editing tools.
Branch builds package downloads without publishing a stable release.
