# Hamsy 0.5.0-beta.1

An experimental agent interface bundled in the release executable.

- `hamsy mcp`: local stdio MCP server using the official Rust SDK, with tool and
  documentation discovery. Connects to an existing Hamsy instance.
- `hamsy mcp --print-config`: copyable client configuration using the executable's
  absolute path, with configurable loopback API URL.
- Read-only traffic inspection, settings/rules inspection and redacted HAR exports.
- Optional `--allow-writes` enables rule changes, capture pause/resume and replay.
- `hamsy agent-guide` and JSON `hamsy agent tools` / `hamsy agent call` provide
  a fallback for agents without MCP.
- Bounded output and body previews; best-effort credential redaction; no automatic
  system proxy changes or certificate installation by the agent interface.

See `hamsy agent-guide` or docs/AGENT_GUIDE.md. The beta operates on live server
state; browser-only imported HAR tabs are not available. Full HAR exports remain
available through the web UI. `hamsy update` follows stable releases, not betas.

Pushes to w-mcp-beta create workflow build artifacts only. A beta tag, if published
separately, is marked as a GitHub prerelease and does not replace the stable release.
