# Hamsy 0.5.0-beta.2

Agents can now inspect open sessions from live Hamsy capture and imported HARs,
including external files opened through the standalone desktop HAR viewer.

- New `list_sessions` tool discovers available captures and open imported tabs.
- `list_flows`, `get_flow`, and `export_har` accept the returned `sessionId`.
  Existing calls without it still use live capture.
- Imported sessions support forward pagination and remain read-only, even when
  the agent connection enables writes. Imports never enter the live capture.
- Standalone viewer discovery uses the current Hamsy profile and verifies viewer
  identity. `--viewer-data-dir` selects a custom profile. Capture can be stopped.
- Browser sessions are discovered from metadata and loaded on demand. Keep their
  browser windows open; closing tabs or disconnecting withdraws them.
- The embedded guide and Setup page describe session selection and limitations.
- Includes desktop HAR opening support from the app branch.

There are 13 tools: 8 available by default and 5 additional actions with
`--allow-writes`. Text previews and HAR exports retain the beta's size limits and
best-effort credential redaction. Reload browser pages after updating the beta.

Pushes to `w-mcp-beta` build downloadable workflow artifacts without publishing a
stable release. `hamsy update` still follows the stable channel.
