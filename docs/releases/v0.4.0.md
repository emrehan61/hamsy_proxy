# HAR search and host exclusions

- **Search HAR contents:** Search URLs, headers, query parameters, request and response text bodies, and WebSocket messages across an imported HAR. Base64-encoded text bodies are decoded for searching.
- **Text or regex:** Use literal text by default, enable regular expressions, or turn on case-sensitive matching. Invalid patterns show an error; slow searches can be cancelled without blocking the interface.
- **Jump to a request:** Results show a highlighted preview of the first match in each matching field. Click a result to reveal its request in the list and open the relevant detail tab.
- **Exclude hosts:** Hide one or more hosts using the new multi-select beside All hosts, in both live traffic and imported HAR sessions. Exclusions also apply to HAR search results and filtered exports.

HAR search respects the filters above the results. Binary bodies and bodies absent from the HAR cannot be searched as text.
