# Full-content search in the current session

- **Search session:** Search captured URLs, headers, query parameters, request and response text bodies, and WebSocket messages from the live traffic toolbar.
- **Regex and match case:** Use the same regular-expression and case-sensitive search options available in imported HAR sessions, including base64-encoded text bodies.
- **Open matching details:** Results respect the current filters. Click a match to select its request and open the corresponding detail tab.
- **Refresh captured contents:** Search uses a stable snapshot. Click Refresh to include newer traffic, updated responses, and WebSocket messages.

Session contents load with bounded concurrency and cancellation. Requests evicted during loading are skipped; connection failures can be retried with Refresh. Slow regular expressions run in a cancellable worker so they cannot block the interface.
