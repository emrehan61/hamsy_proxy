# Hamsy 0.5.0-beta.3

- New read-only `search_flows` MCP tool searches live capture and open HAR
  sessions, including standalone viewer sessions.
- Literal and regex search, case sensitivity, host exclusions, host/method/status
  filters, and forward pagination.
- Searches retained URLs, headers, query parameters, text request/response
  bodies, base64 text, and text WebSocket messages. Results identify matching
  requests and fields; raw snippets are omitted.
- Live searches read current capture snapshots without a browser. Repeat calls
  to follow changes; MCP does not push a continuous event stream.
- HAR regex runs in a terminable worker, with a six-second timeout. Live regex
  runs off the capture loop and disallows lookaround/backreferences.
- 14 tools total: 9 read-only by default and 5 gated by `--allow-writes`.

Reload open Hamsy browser windows after updating. See `hamsy agent-guide` for
examples, pagination, regex syntax differences, and limitations.

This branch builds beta artifacts only and does not publish to stable releases.
